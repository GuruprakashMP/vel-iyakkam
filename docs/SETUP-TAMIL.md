# வேல் இயக்கம் — இணையதள கையேடு
### Vel Iyakkam — Website Handbook

இந்தக் கையேடு உங்களுக்காக மட்டும். ஒரு முறை அமைத்துவிட்டால், பிறகு ஒவ்வொரு மாதமும்
**கூகிள் சீட்டில் ஒரு வரி எழுதினால் போதும்** — இணையதளம் தானாகவே புதுப்பிக்கும்.

---

## பகுதி 1 — கூகிள் சீட் உருவாக்குதல் (ஒரு முறை மட்டும்)

### படி 1: புதிய சீட் உருவாக்குங்கள்

1. [sheets.new](https://sheets.new) என்ற முகவரிக்குச் செல்லுங்கள்
2. மேலே இடதுபுறம் பெயரை `Vel Iyakkam Data` என்று மாற்றுங்கள்

### படி 2: நான்கு தாள்களை (tabs) உருவாக்குங்கள்

கீழே இடதுபுறம் `+` அழுத்தி நான்கு தாள்களை உருவாக்கி, சரியாக இந்தப் பெயர்களைக் கொடுங்கள்:

| தாள் பெயர் | எதற்கு | கட்டாயமா? |
|---|---|---|
| `Donations` | மாதாந்திர வரவு | ✅ ஆம் |
| `Expenses` | செலவு / உதவி | ✅ ஆம் |
| `Stories` | கதைகள் | ✅ ஆம் |
| `Donors` | உறுப்பினர் முதன்மைப் பட்டியல் | ⬜ விருப்பம் |

> ⚠️ **முக்கியம்:** முதல் வரியில் உள்ள தலைப்புகள் (headings) அப்படியே இருக்க வேண்டும்.
> தலைப்பை மாற்றினால் இணையதளம் தரவைப் படிக்காது.

### தாள் 1 — `Donors` (உறுப்பினர் முதன்மைப் பட்டியல்) — *விருப்பம்*

> இந்தத் தாள் **உங்கள் சொந்தப் பதிவுக்காக மட்டும்**. இணையதளத்தில் காட்டப்படும் எல்லா
> எண்களும் `Donations` தாளிலிருந்தே கணக்கிடப்படுகின்றன. இதை உருவாக்காவிட்டாலும்
> இணையதளம் முழுமையாக இயங்கும்.
>
> **ஏன் "இந்த மாதம் யார் கொடுக்கவில்லை" என்ற பட்டியல் இணையதளத்தில் இல்லை?**
> அதைப் போட்டால் குறியீடு முறையின் நோக்கமே அழிந்துவிடும். கொடுக்காதவரை
> பொதுவில் சுட்டிக் காட்டுவது சங்கடத்தை உண்டாக்கும் — ஒருவேளை அந்த மாதம்
> அவருக்கே கஷ்டமாக இருந்திருக்கலாம். நினைவூட்ட வேண்டுமானால் தனிப்பட்ட
> முறையில் செய்யுங்கள்.


| Code | JoinedMonth | Active | Notes |
|---|---|---|---|
| VI-001 | 2026-02 | Yes | |
| VI-002 | 2026-02 | Yes | |

- **Code** — ஒவ்வொருவருக்கும் ஒரு தனி எண். `VI-001`, `VI-002` என வரிசையாக.
- **JoinedMonth** — சேர்ந்த மாதம், `YYYY-MM` வடிவில்.
- **Active** — இப்போதும் தருகிறாரா? `Yes` அல்லது `No`.

> 🔒 **பெயரை இங்கே எழுத வேண்டாம்.** யாருக்கு எந்தக் குறியீடு என்பதை
> **தனி நோட்டுப் புத்தகத்திலோ அல்லது தனி (பகிரப்படாத) சீட்டிலோ** வைத்துக் கொள்ளுங்கள்.
> இந்த சீட் இணையத்தில் வெளியிடப்படும் — பெயர் இருந்தால் அது பொதுவில் தெரிந்துவிடும்.

### தாள் 2 — `Donations` (மாதாந்திர வரவு) ← **இதுதான் ஒவ்வொரு மாதமும் நிரப்ப வேண்டியது**

| Code | Month | Amount | PaidDate | Method | Status | Note |
|---|---|---|---|---|---|---|
| VI-001 | 2026-08 | 500 | 2026-08-09 | UPI | Paid | |
| VI-002 | 2026-08 | 1000 | 2026-08-12 | UPI | Paid | |
| VI-004 | 2026-08 | 100 | | | Pending | |

- **Month** — `2026-08` இப்படி. (எந்த மாதத்திற்கான நன்கொடை)
- **Amount** — எண் மட்டும். `₹` சின்னமோ கமாவோ வேண்டாம். `500` ✓ &nbsp; `₹5,00` ✗
- **PaidDate** — `2026-08-09`. தெரியாவிட்டால் காலியாக விடலாம்.

- **Status** — `Paid` அல்லது `Pending`. **காலியாக விட்டால் `Paid` என்று எடுத்துக்கொள்ளும்.**
  `Pending` என்று போட்டால் மொத்தத் தொகையில் சேராது, ஆனால் பட்டியலில் தெரியும்.

## பகுதி 2 — சீட்டை இணையத்தில் வெளியிடுதல்

ஒவ்வொரு தாளுக்கும் **தனித்தனியாக** இதைச் செய்ய வேண்டும் (மொத்தம் 4 முறை):

1. மேலே **File** → **Share** → **Publish to web** அழுத்துங்கள்
2. **Link** தாவலில்:
   - இடதுபுறம் **முழு ஆவணம் அல்ல** — அந்தத் **தாளின் பெயரைத்** (எ.கா. `Donations`) தேர்ந்தெடுங்கள்
   - வலதுபுறம் **Comma-separated values (.csv)** தேர்ந்தெடுங்கள்
3. **Publish** → **OK** அழுத்துங்கள்
4. வரும் இணைப்பை **நகல் எடுங்கள் (Copy)**

இணைப்பு இப்படி இருக்கும்:
```
https://docs.google.com/spreadsheets/d/e/2PACX-1vT.../pub?gid=0&single=true&output=csv
```

## பகுதி 3 — இணைப்புகளை இணையதளத்தில் சேர்த்தல்

1. GitHub-இல் உங்கள் repository-க்குச் செல்லுங்கள்
2. `assets` → `js` → `config.js` கோப்பைத் திறங்கள்
3. வலது மேலே **பென்சில் ✏️** சின்னத்தை அழுத்துங்கள்
4. `sheets:` பகுதியைக் கண்டுபிடித்து, மேற்கோள் குறிகளுக்கு (`' '`) **இடையில்** இணைப்பை ஒட்டுங்கள்:

```js
  sheets: {
    donors:   'https://docs.google.com/.../pub?gid=0&single=true&output=csv',
    donations:'https://docs.google.com/.../pub?gid=111&single=true&output=csv',
    expenses: 'https://docs.google.com/.../pub?gid=222&single=true&output=csv',
    stories:  'https://docs.google.com/.../pub?gid=333&single=true&output=csv'
  },
```

5. கீழே **Commit changes** அழுத்துங்கள்
6. **1–2 நிமிடம்** காத்திருந்து இணையதளத்தைப் புதுப்பியுங்கள் (refresh)

✅ இப்போது உங்கள் தரவு இணையதளத்தில் தெரியும்.

> ⚠️ கமாவை (`,`) நீக்கிவிடாதீர்கள். கடைசி வரியில் (`stories`) மட்டும் கமா இல்லை.

## பகுதி 5 — கூகிள் படிவங்கள் (Google Forms) — விருப்பம்

மக்களே கதை அனுப்ப, உதவி கோர, உறுப்பினராகச் சேர படிவங்கள் வைக்கலாம்.

3. படிவ இணைப்பை நகல் எடுத்து `config.js`-இல் `forms:` பகுதியில் ஒட்டுங்கள்

**கதை படிவத்தில் கேட்க வேண்டியவை:** Title, Category, Story, Moral, Contributor

> 💡 படிவ பதில்கள் வரும் தாளின் தலைப்புகளை `Title`, `Category`, `Story`, `Moral`,
> `Contributor` என்று மாற்றி, `Status` என்ற ஒரு நெடுவரிசையைக் கையால் சேருங்கள்.
> நீங்கள் படித்துப் பார்த்து `published` என்று எழுதினால் மட்டுமே இணையதளத்தில் தெரியும்.

## பகுதி 6 — வேறு என்ன மாற்றலாம்

`assets/js/config.js` கோப்பில்:

| அமைப்பு | என்ன செய்யும் |
|---|---|
| `org.upiId` | நன்கொடை பக்கத்தில் UPI முகவரி காட்டும் |
| `org.contactPhone`, `org.whatsapp` | தொடர்பு எண் காட்டும் |
| `panchang.latitude` / `longitude` | சஷ்டி கணக்கீட்டுக்கான ஊர் (இப்போது திருச்செந்தூர்) |
| `display.defaultLang` | `'ta'` = தமிழ் முதலில், `'en'` = ஆங்கிலம் முதலில் |
| `display.showAmountsPublicly` | `false` ஆக்கினால் தொகை மறைந்து, யார் கொடுத்தார் மட்டும் தெரியும் |
| `display.sashtiYearsAhead` | எத்தனை ஆண்டு சஷ்டி தேதிகள் காட்ட வேண்டும் |

**கல்வி வழிகாட்டி** உள்ளடக்கத்தை மாற்ற: `data/guidance.json`
**வார்த்தைகளை** மாற்ற (தமிழ்/ஆங்கிலம்): `assets/js/i18n.js`

## 🔒 தனியுரிமை — மறக்கக் கூடாதவை

1. **நன்கொடையாளர் பெயரை** எந்த தாளிலும் எழுத வேண்டாம் — குறியீடு மட்டும்
2. **உதவி பெறும் குழந்தையின் பெயரையோ, பள்ளிப் பெயரையோ, புகைப்படத்தையோ** வெளியிட வேண்டாம்
3. தொலைபேசி எண், முகவரி — இணையதளத்தில் வேண்டாம்
4. குறியீடு ↔ பெயர் பட்டியலை **தனியாக, பகிரப்படாத** இடத்தில் வைக்கவும்

இந்த இணையதளம் வேண்டுமென்றே இப்படி வடிவமைக்கப்பட்டுள்ளது — கொடுப்பவர் யாரென்று
யாருக்கும் தெரியாது, ஆனால் ஒவ்வொரு ரூபாயும் எங்கே போனது என்று எல்லாருக்கும் தெரியும்.
